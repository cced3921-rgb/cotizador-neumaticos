Conexion con Meta (formularios de Facebook / Instagram)

Cuando alguien llena un formulario de "clientes potenciales" en un anuncio de Facebook o Instagram, se crea el contacto solo en el CRM (sin tener que copiarlo a mano).

{{ '🟢 Conectado' if ajustes.meta_page_access_token else '⚪ Todavia no conectado' }}
Como conectarlo (pasos en Meta)
  1. Entra a developers.facebook.com, crea una app tipo "Negocios" (o usa una que ya tengas) conectada a tu Business Manager.
  2. Agrega el producto Webhooks a esa app.
  3. En la configuracion del webhook pon esta URL de devolucion de llamada y el token de verificacion de abajo, y suscribete al campo leadgen de tu pagina de Facebook.
  4. Genera un token de acceso de pagina con permiso leads_retrieval (desde el Explorador de la API Graph, con tu pagina seleccionada) y pegalo abajo.
  5. Guarda - en cuanto alguien llene el formulario del anuncio, aparece solo en tu CRM.

Asistente de IA (WhatsApp)

Cuando alguien escribe por WhatsApp, el asistente lee el mensaje, hace las preguntas necesarias para preparar al cliente (que vehiculo o medida busca, cuantas llantas, con que urgencia) y le pone una prioridad (🔥 caliente / 🌤 tibio / ❄ frio) para que el vendedor sepa a quien atender primero. Se puede pausar en cualquier momento desde el detalle de cada contacto.

{{ '🟢 Conectado' if ajustes.anthropic_api_key and ajustes.whatsapp_access_token else '⚪ Todavia no conectado' }}
Como conectarlo (pasos en Meta)
  1. En la misma app de Meta (developers.facebook.com), agrega el producto WhatsApp.
  2. En la configuracion de WhatsApp → Webhooks, usa la misma URL y token de verificacion de arriba, y suscribete al campo messages.
  3. Copia el ID del numero de telefono (Phone number ID) y el token de acceso temporal que te da Meta para el numero de prueba, y pegalos abajo.
  4. Consigue tu API key de IA en console.anthropic.com y pegala abajo tambien.
  5. Guarda y activa el asistente - en cuanto alguien escriba al numero de prueba, el asistente contesta solo.
